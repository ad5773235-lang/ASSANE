# Audit de la base existante Assane AI

Le projet existant est conservé comme base de travail. La refonte est incrémentale : les écrans d’authentification OTP, le backend FastAPI, les tâches, l’arrêt/reprise, l’importation, l’inspection, le navigateur, la génération d’images, les artefacts, l’aperçu, les builds Android, la publication et le profil ne doivent pas être supprimés.

Les deux références visuelles fournies pour l’Ordinateur d’Assane sont conservées dans `docs/ui_references/` sous les noms `reference_ordinateur_assane_01.png` et `reference_ordinateur_assane_02.png`. Elles restent les références principales de la nouvelle architecture visuelle.

L’écran de connexion ne doit pas afficher un grand logo. L’icône Assane AI reste l’icône principale Android déclarée dans le manifeste.

La prochaine amélioration doit donc compléter l’interface existante autour de trois espaces réels : Accueil/Chat, Historique des tâches enregistrées et Ordinateur d’Assane regroupant navigateur, inspection, fichiers/import, éditeur, terminal, aperçu, artefacts, build et publication.
